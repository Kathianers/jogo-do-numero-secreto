# 🎮 Jogo do Número Secreto

Projeto desenvolvido durante o curso de **Lógica de Programação** da **Alura**.
O objetivo do jogo é adivinhar o número secreto gerado aleatoriamente entre 1 e 10 com o menor número de tentativas possíveis.

## 🛠️ Linguagens utilizadas:
- HTML5
- CSS3
- JavaScript

## 🎯 Funcionalidades:
- Geração de números aleatórios sem repetição até o limite estabelecido.
- Validação de tentativas (maior ou menor que o número secreto).
- Opção de reiniciar o jogo após acertar.
- Leitura de texto por voz integrada.
